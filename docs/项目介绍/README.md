## 项目概述

CabinWeave 是面向智能座舱的多 Agent 交互系统。系统接收语音识别后的文本，识别意图后交给车控、导航、用车顾问、座舱助手等 Agent 执行，紧急情况由不调模型的安全节点处理。

技术栈：Python 3.12、FastAPI、AsyncIO、Redis、ChromaDB、Vue 3、Docker Compose；模型通过 Anthropic Messages API 兼容接口调用。
